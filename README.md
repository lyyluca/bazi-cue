# BaZi Cue

A free, browser-accessible BaZi chart calculator with clear explanations and transparent calculation rules. No sign-up required.

Website: [https://bazicue.com](https://bazicue.com)

## Features
- Four Pillars chart calculation
- Day Master identification
- Five Elements information
- Clear explanations & transparent rules

## How to use
1. Open https://bazicue.com.
2. Enter birth information.
3. Generate and review your BaZi chart.
